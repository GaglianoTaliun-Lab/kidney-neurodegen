# Stage 02 — Conjunctional FDR (pleioFDR)

This stage identifies genomic loci jointly associated with PD and each kidney-related
trait using conjunctional false discovery rate (conjFDR). 

## Software used

- **pleioFDR** (MATLAB) — conditional/conjunctional FDR analysis.
  Repository: https://github.com/precimed/pleiofdr
